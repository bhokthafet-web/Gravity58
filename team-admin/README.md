# Gravity58 Unified Team Admin

This is the only administration portal in the release. Access requires a G58 email/password account with an administrator role; there is no shared or embedded administrator password.

It manages advertisement bookings, payment links, campaign activation and expiry, advertiser profiles, product subscriptions and restaurant advertising placements. Follow `g58-core/README.md` and never put server secrets in frontend code.

Permanent deletion of an account is performed by a protected G58 Core action after administrator authorization. The browser portal never contains server credentials.
